## 적용 기준과 경계

- 사용자가 필요한 운영규칙 전체 적용을 요청했다. 이 승인은 코팡의 가역적 운영 문서·양식·상태 보완 범위다. 앱 소스·실제 branch/commit/push/PR/merge·원격 보호/Secret/권한·WYBU/원팀 변경 승인이 아니다.
- 그대로는 운영 의미 유지, 수정은 원칙을 코팡의 상태·경로·권한·단순 Markdown으로 매핑, 제외는 WYBU 제품/Runtime/형식 또는 아직 조건이 없는 구조를 가져오지 않는 판단이다. 제외할 때 일반 원칙까지 함께 버리지 않는다.
- 원본 Work는 단일 WORK 파일이 아닌 Fast/WP 경로와 Roadmap→Area→WP→Stage(Task+Gate), Evidence/Execution Packet 및 단일 Writer 체계다. 코팡은 [WORK](./work-status/WORK.md)와 [상태 운영 정본](./work-status/README.md)에 이 역할·상태·검증·생성 조건을 보존하며 불필요한 전체 ID/schema/폴더만 제외한다.
- 개인 Git 기본 절차는 이번 보완 요청의 문서 적용으로 채택했다. 실제 서버 보호/merge 설정은 미확인이다. 현재 dirty main의 운영 문서 bootstrap은 보존하고 이후 변경은 작업 branch/worktree 정책을 따른다.
